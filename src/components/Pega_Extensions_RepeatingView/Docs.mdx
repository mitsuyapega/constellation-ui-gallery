# Overview

Repeating View component displays hierarchical data in a parent-child relationship format. Each parent record can be expanded to show its related child records in a table format. This component supports both property-based and data page-based data sources.

Key features:

- Expandable/collapsible parent records
- Tabular display of child records
- Support for both property and data page data sources
- Configurable column display for both parent and child records
- Target views support for additional content
